# Emergency QR — frontend

Сайт и приложение Expo, контракт `emergency-qr-v1`. Обновлённый интерфейс
по макету: красный акцент, горная главная, форма из трёх шагов, QR и профиль,
страницы помощи и информации о проекте. Запуск на физическом Expo Go ещё
не проверен; web и экспорт native-пакетов не заменяют такой запуск.

- [Запуск, настройки API и передача команде](README_FRONTEND.md)
- [Выполненные проверки и ограничения](CHECKS_FRONTEND.md)
- [Настоящая интеграция с API и SQLite](../CHECKS_PROJECT.md)
- [Подготовка постоянного HTTPS-адреса](../docs/DEPLOYMENT.md)

Это модуль Мики в объединённом проекте. Соседние `backend/` и `database/`
реализуют API и SQLite. Общий запуск: [корневой README](../README.md).
